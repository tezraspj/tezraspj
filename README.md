# Express Еда — сайт доставки (Пенджикент)

Одностраничный сайт доставки еды: заведения, меню, корзина, оформление
заказа через WhatsApp.

## Запуск

Открыть `public/index.html` в браузере, либо локальный сервер:

```bash
python -m http.server 8765 --directory public
# → http://localhost:8765
```

Интернет нужен: шрифты (Unbounded, Manrope) и фото подтягиваются с CDN
(Google Fonts, Unsplash).

## Дизайн

Стиль NIMA (по референсу): чёрный фон, жёлтый акцент `#FFD600`, крупные
курсивные заголовки (Archivo), карточки заведений и блюд, нижняя навигация
на мобильных. Тёмная тема по умолчанию + переключатель на светлую. Все
функции и данные прежние.

## Что внутри

```
public/
├── index.html      весь сайт: разметка + стили + логика в одном файле
├── img/            место под локальные картинки (сейчас не используется)
index.backup.html         резервная копия оригинала (Tailwind, из index.zip)
index.orange.backup.html  версия с оранжевым дизайном (промежуточная)
index.zip           исходный архив с сайтом (оригинал)
style (2).md        мастер-промт OKTASHOP (для другого проекта)
docs/               документация
data/ server/ src/ tests/  — заготовки под развитие проекта
```

## Возможности

- список заведений с фильтрами (фастфуд, уличная еда, чайхана, суши);
- меню заведения с категориями блюд и поиск;
- корзина: количество, промокод (SALE10), доставка по городу, итог;
- форма заказа (имя, телефон, адрес, комментарий) → кнопка «Заказать через
  WhatsApp»;
- тёмная тема.

## Настройка под себя

Всё в одном файле `public/index.html`:

- заведения и блюдa — массивы в JS-блоке (поиск `const restaurants`);
- доставка и промокод — блок `deliveryFee` / промокоды;
- WhatsApp-номер — функция отправки заказа (ищите `wa.me`).
