# Технический аудит (до доработки)

## Структура

- Весь сайт (разметка, стили, логика, данные) находился в одном файле
  `public/index.html` (~142 КБ) — невозможно поддерживать и масштабировать.
- CSS и JS-дубликаты: инлайн-обработчики (`onclick`) в разметке +
  повторяющиеся блоки стилей.
- `docs/`, `data/`, `server/`, `src/`, `tests/` — пустые заготовки.
- Зависимости: только CDN (Google Fonts, Unsplash), backend отсутствовал.

## Найденные ошибки и проблемы

1. **Доставка**: порог бесплатной доставки не был формализован; расчёт
   мог расходиться при изменении количества.
2. **Корзина**: не сохранялась после перезагрузки; не было запрета на
   смешивание блюд разных ресторанов; изменение количества и удаление
   позиций были реализованы частично/некорректно.
3. **Промокоды**: проверка на клиенте, без единого источника правды.
4. **События**: обработчики висели на inline-атрибутах и терялись при
   перерисовке DOM (карточки пересобирались через `innerHTML`).
5. **Форма заказа**: поля (имя/телефон/адрес/комментарий) не валидировались.
6. **Цены**: при оформлении суммы считались на клиенте, серверной
   проверки не было (риск подмены цены).
7. **Нет backend**: заказы уходили только в WhatsApp, статусы и
   уведомления не велись.
8. **Секреты**: отсутствовали переменные окружения, всё было «как есть».

## План исправлений

1. Разбить `index.html` на `css/style.css` + `js/config.js`, `js/data.js`,
   `js/api.js`, `js/app.js` (сохранив дизайн и разметку).
2. Переписать логику корзины: единый `computeTotals`, localStorage,
   запрет смешивания ресторанов, количество/удаление, подсказка доставки.
3. Валидация формы (имя/телефон/адрес/комментарий) на клиенте.
4. Интеграционный слой `AppAPI` с fallback на локальные данные/WhatsApp.
5. Backend: FastAPI + SQLAlchemy + Alembic + Pydantic; серверный пересчёт
   цен/доставки/скидки; валидация; rate limiting; PBKDF2; Telegram.
6. Admin API (Bearer-токен) + веб-админка `public/admin/`.
7. Тесты (pytest) и smoke-тест против живого сервера.
8. Документация (README, audit) и публикация.
